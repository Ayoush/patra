# State aliases

Indian states have official names, abbreviations, and historical names that appear in real addresses. patra maps all of them to the official name.

## Examples

| Raw | Normalized |
|-----|------------|
| OR | Odisha |
| Orissa | Odisha |
| UK | Uttarakhand |
| Uttaranchal | Uttarakhand |
| MP | Madhya Pradesh |
| Bombay | Maharashtra |
| Madras | Tamil Nadu |

## Source

The alias table is hand-curated in `spec/aliases/`. See `docs/privacy.md` for the data policy.
